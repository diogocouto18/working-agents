# Contributing

Thanks for taking a look. This is a small personal project, so the process
is light.

## Setup

Requirements: Node.js 20.19+ and npm. Python 3 is only needed for the helper
scripts.

```bash
git clone https://github.com/diogocouto18/working-agents.git
cd working-agents
npm install
npm run dev        # http://localhost:4242
npm test           # node:test, no extra tooling
```

To try the UI without real Claude Code sessions, point the server at a
scratch directory of synthetic transcripts:

```bash
WORKING_AGENTS_PROJECTS_DIR=/tmp/demo-sessions npm run dev
```

Each session is `<dir>/<project>/<id>.jsonl`; `server/sessionParser.js`
shows the fields it reads.

## Making a change

1. Open an issue first for anything bigger than a small fix.
2. Branch from `master`; one topic per pull request.
3. Add or update tests for server-side logic (`server/`). Tests live in
   `test/` and use the built-in `node:test` runner.
4. Run `npm test` before pushing. CI runs the same command on Node 20 and 22.
5. For UI changes, run the server and check the result in a browser;
   screenshots in the PR help.

## Commit messages

`[Type] Brief Description In Title Case`, for example
`[Fix] Handle Sessions Without A Working Directory`. Common types: `Doc`,
`Fix`, `Backend`, `Frontend`, `Test`, `CI`, `Chore`.

## Code style

- ES modules, no build step, no runtime dependencies beyond `ws` and
  `chokidar`.
- Keep the server local-only and safe by default: it has no authentication,
  so do not weaken the loopback binding or the `Host`/`Origin` checks.
- Write code, comments and docs in English.

## Assets

The office background and sprites are generated by
`scripts/generate-office.py` from the packs in `assets-src/`. Any new asset
needs a compatible license and an entry in `CREDITS.md`.
